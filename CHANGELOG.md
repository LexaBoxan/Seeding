# Журнал изменений

Все значимые изменения проекта фиксируются в этом файле.
Формат основан на принципе `Keep a Changelog`.

## [В разработке]

### Добавлено

- Ручная корректировка структуры объектов в дереве слоёв:
  - добавление частей растения из контекстного меню для узла сеянца и узла части;
  - добавление сеянца на страницу из контекстного меню корневого узла;
  - удаление лишних частей/дубликатов через контекстное меню.
- Разделение статистики по категориям:
  - сеянцы;
  - соцветия;
  - стебли;
  - корни;
  - прочие части.
- Документ для разработчика `DEVELOPER_GUIDE_RU.md` с правилами правок и smoke-сценариями.
- `StorageService` (`seeding/storage.py`) для:
  - локального кэша детекции;
  - локального кэша классификации;
  - истории измерений (`JSONL`) и экспорта истории в `CSV`.
- Параметры в `SettingsDialog`:
  - калибровка `px/mm`;
  - переключатель использования кэша.
- Кэширование в рабочих сценариях:
  - загрузка/сохранение результатов детекции;
  - загрузка/сохранение результатов классификации.
- Журнал измерений из контекстного меню дерева:
  - расчёт `px`;
  - расчёт `mm` при заданной калибровке;
  - просмотр истории измерений;
  - экспорт истории измерений в `CSV`.
- Управление кэшем из меню (`Очистить кэш`).
- Отмена пакетной детекции через `QProgressDialog`.
- Новые unit-тесты `tests/test_storage_service.py`.
- Новые unit-тесты `tests/test_tree_widget.py` для фильтрации по confidence.
- Новые регрессионные тесты `tests/test_main_window_resilience.py`:
  - отсутствие падения в `eventFilter` при повреждённом состоянии инструмента;
  - отсутствие падения в `_on_find_all_progress` без progress dialog.
- Новые тесты локализации панелей: `tests/test_ui_localization_panels.py`.
- Интерактивный инструмент `Линейка (M)` на canvas:
  - выбор двух точек мышью;
  - отображение расстояния в `px/mm`;
  - запись результата в историю измерений.
- Интерактивная калибровка из настроек:
  - кнопка `Калибровка по линейке` в `SettingsDialog`;
  - измерение эталонного отрезка на активной странице;
  - ввод реальной длины в мм с автоматическим расчётом `px/mm`.

### Изменено

- `main_window.py` расширен сценариями:
  - применения кэша;
  - просмотра истории измерений;
  - отмены пакетной обработки.
- В `Найти все` добавлена догрузка из кэша с частичным пересчётом только отсутствующих страниц.
- Фильтр дерева слоёв переведён на числовое значение confidence в metadata узла (без парсинга текста).
- Закрытие окна теперь корректно завершает фоновые потоки и закрывает progress dialog.
- Удалён неиспользуемый заглушечный пакет `seeding/processing`.
- CI: обновлены цели `flake8` (добавлен `seeding/storage.py` и новые тесты).
- README полностью обновлён под актуальную структуру и функциональность.
- `theme_manager.py`: по умолчанию применяется проектный QSS без `qt-material`;
  `qt-material` включается только через `SEEDING_USE_QT_MATERIAL=1`.
- Локализация ru/en расширена на:
  - заголовки и контекстное меню дерева слоёв;
  - подписи панели статистики;
  - подсказки панели миниатюр;
  - экспорт CSV статистики;
  - сообщения линейки/калибровки, истории измерений и очистки кэша.
- Подпись линейки на canvas сделана статичной по масштабу (не уменьшается при зуме).
- Темы `dark/light` дополнены единым стилем полей ввода, кнопок, комбобоксов и чекбоксов для целостного вида UI.

### Исправлено

- Падение `AttributeError: _active_tool` при раннем событии мыши в canvas.
- Потенциальные ошибки доступа к состоянию инструмента в `eventFilter` и
  обработчиках `Space/Esc`.
- Потенциальное падение в `_save_layout_settings` при отсутствии `_active_tool`.

## [4.0.0] - 2026-02-19

### Добавлено

- Трёхколоночный интерфейс (`toolbox` слева, canvas по центру, панели справа).
- Вкладки `Слои/Свойства`, затем расширение до `Слои/Свойства/Статистика/Миниатюры`.
- Система тем (`dark/light`) и локализация (`ru/en`).
- `IconManager`, `UiMetrics`, сохранение layout через `QSettings`.
- Базовый слой `controllers/services/models`.
- Экспорт результатов в `JSON/CSV/COCO/YOLO` и экспорт изображений с аннотациями.

### Изменено

- Поворот изображений синхронизирован с пересчётом `bbox`.
- Обрезка `bbox` ограничена размерами изображения с валидацией координат.
- Проверка путей к весам сделана кроссплатформенной.
- Генерация PDF обновлена: корректные переносы без лишних пустых страниц.

### Исправлено

- Ошибки при выходе координат за границы изображения.
- Некорректное сохранение отчётов при пустом `file_path`.
- Ошибки обработки относительных/абсолютных путей на Windows.

## [3.2.x] - Legacy

- Версия до рефакторинга 4.0 (монолитный UI и частичная изоляция логики).

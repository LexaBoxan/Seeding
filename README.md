# Seeding 4.0.0

Seeding Detection — настольное приложение для анализа сеянцев и растительного материала на изображениях и PDF.
Программа выполняет детекцию, классификацию частей, измерения, экспорт данных и формирование PDF-отчётов.

## Ключевые возможности

- Детекция сеянцев (YOLO) по изображению и по всем страницам PDF.
- Корректный поворот изображений с пересчётом `bbox`.
- Классификация частей растения внутри найденных объектов.
- Экспорт результатов в `JSON`, `CSV`, `COCO`, `YOLO` и экспорт изображений с аннотациями.
- Генерация PDF-отчёта по текущему проекту.
- Правая панель: слои, свойства, статистика, миниатюры.
- Локальный кэш детекции и классификации (с очисткой через меню).
- Измерения объектов в `px` и `mm` (после калибровки), журнал измерений и экспорт журнала в `CSV`.
- Тёмная/светлая темы и локализация интерфейса `ru/en`.

## Интерфейс

Приложение использует трёхколоночный layout:

- Левая панель (`toolbox`): все основные действия и инструменты (`Select`, `Hand`, `Zoom`, `Measure`).
- Центр: canvas просмотра изображения/страницы.
- Правая панель: вкладки `Слои`, `Свойства`, `Статистика`, `Миниатюры`.
- Верхняя часть: строка меню (`Файл`, `Вид`, `Анализ`).

## Требования

- Python `3.10+`
- Windows / macOS / Linux

## Установка

```bash
python -m pip install -e .
```

Или установка зависимостей напрямую:

```bash
python -m pip install -r seeding/requirements.txt
python -m pip install -r requirements-dev.txt
```

## Запуск

```bash
python -m seeding.main
```

С явным путём к весам детекции:

```bash
python -m seeding.main --weights models/bestCrop.pt
```

## Переменные окружения

- `YOLO_WEIGHTS_PATH` — путь к весам детектора.
- `YOLO_CLASSIFY_WEIGHTS_PATH` — путь к весам классификатора.
- `SEEDING_USE_QT_MATERIAL` — включение `qt-material` (`1/true/on`).
  По умолчанию отключено, используется проектный QSS (это убирает ошибки вида
  `icon:/primary/...` на части систем).

## Настройки в приложении

Диалог `Настройки` сохраняет параметры в `QSettings`:

- пороги уверенности (`conf_high`, `conf_low`, `detect_conf`, `detect_iou`);
- путь к модели детекции и классификации (`.pt`);
- папка отчётов по умолчанию;
- калибровка `px/mm`;
  калибровка также поддерживает интерактивный режим:
  в `Настройках` нажмите `Калибровка по линейке`, измерьте эталонный отрезок
  на активном изображении и введите его длину в мм;
- флаг использования локального кэша;
- тема и язык интерфейса.

## Горячие клавиши

- `Ctrl+O` — открыть файлы
- `Ctrl+Shift+O` — добавить файлы
- `Ctrl+S` — сохранить изменения
- `Ctrl+E` — экспорт результатов
- `Ctrl+P` — создать PDF-отчёт
- `Ctrl+F` или `D` — детекция на текущем изображении
- `Ctrl+Shift+F` — детекция на всех изображениях
- `Ctrl+C` — классификация частей
- `Ctrl+R` или `R` — поворот
- `Ctrl++`, `Ctrl+-`, `Ctrl+0` — зум / вписать
- `V`, `H`, `Z`, `M` — инструменты `Select`, `Hand`, `Zoom`, `Measure`
- `Space` (удерживать) — временный `Hand`
- `Left/Right` — переключение изображений

## Типовой сценарий

1. Открыть изображение или PDF.
2. Запустить детекцию (`Ctrl+F` или `Ctrl+Shift+F`).
3. Проверить объекты в дереве слоёв.
4. Выполнить классификацию (`Ctrl+C`) при необходимости.
5. Выполнить измерения из контекстного меню дерева или инструментом `Measure (M)` на canvas.
6. Сохранить отчёт (`Ctrl+P`) или экспорт (`Ctrl+E`).

## Диагностика

- Если не загружается модель: проверьте путь к `.pt` в настройках.
- Если нет результатов детекции: проверьте, что модель успешно загружена.
- Если отчёт/экспорт не сохраняется: проверьте права на целевую папку.

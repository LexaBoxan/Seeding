# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| `4.x` | Yes |
| `<4.0` | No |

Support here means security fixes are considered for the latest `4.x`
development line.

## Reporting a vulnerability

Please do not disclose vulnerabilities in a public issue first.

Send a private report through GitHub Security Advisories if the repository has
that feature enabled. If it is not available, contact the maintainer privately
through GitHub and include:

- affected version or commit;
- reproduction steps;
- expected impact;
- logs, screenshots, or sample files if they are needed to reproduce.

## Response targets

- Initial acknowledgement: within 5 business days.
- Triage/update: within 10 business days when reproduction is available.

## Scope notes

- Model weights, datasets, and third-party assets may have their own separate
  licenses and distribution restrictions.
- Do not include secrets, access tokens, or sensitive production data in
  reports.
